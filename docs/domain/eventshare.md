# EventShare ドメイン

## 概要

予定を第三者にURLで共有するための共有リンクを表すドメイン。予定ごとに複数発行でき、それぞれ固有のトークンと有効期限を持つ。トークンを知っている者はログインなしで対象の予定を閲覧できる。

## 用語定義

| 用語 | 説明 |
|---|---|
| EventShare | 予定に対して発行された共有リンク1件を表すエンティティ。ID・対象予定ID・トークンハッシュ・有効期限を持つ |
| トークン (token) | 共有リンクのURL（`/share/{token}`）に含まれる平文の値。生成時に一度だけ払い出され、DBには保存しない |
| トークンハッシュ (token_hash) | トークンのSHA-256ハッシュ値。DBにはこの値のみを保存し、閲覧時はリクエストされたトークンをハッシュ化して照合する |
| 有効期限 (expires_at) | 共有リンクが閲覧可能な期限。この日時を過ぎるとリンクは無効になる |

## ビジネスルール

- 1つの予定に対して複数の共有リンクを同時に有効な状態で発行できる。新規発行は既存の共有リンクを失効させない
- トークンは `crypto/rand` による32バイトのランダム値をbase64url（パディングなし）でエンコードして生成する（ADR-028）
- 平文トークンはDBに保存しない。DBにはSHA-256ハッシュ値のみを保存する（ADR-028）
- 有効期限は現在時刻を過ぎた時点で失効したとみなす（`expires_at` ちょうどの時刻は失効済み扱い）
- 有効期限と予定の開始日時との整合性チェック（開始日時より前を指定できない等）はEventShare生成時のユースケース層の責務とし、エンティティ自体は`expires_at`が設定されていること以上のバリデーションを持たない

## エラー

| エラー | 発生条件 |
|---|---|
| `ErrEventShareNotFound` | 指定したトークンハッシュに一致する共有リンクが存在しない |
