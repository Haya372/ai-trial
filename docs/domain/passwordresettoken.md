# PasswordResetToken ドメイン

## 概要

ユーザーが忘れたパスワードを再設定するために発行するワンタイムトークンを表すドメイン。再設定申請時に1件発行され、受信者はメール本文のリンク（トークンを含む）から再設定画面を開く。トークンの照合に成功した再設定処理で消費され、以後は使用できない。

## 用語定義

| 用語 | 説明 |
|---|---|
| PasswordResetToken | 再設定トークン1件を表す集約ルート。ID・対象ユーザーID・トークンハッシュ・有効期限を持つ。`User` 集約とは別集約 |
| トークン (token) | 再設定リンクに含まれる平文の値。発行時に一度だけ払い出し、DBには保存しない |
| トークンハッシュ (token_hash) | トークンのSHA-256ハッシュ値（16進文字列）。DBにはこの値のみを保存する |
| 有効期限 (expires_at) | トークンが使用可能な期限。この時刻を含めてそれ以降は失効扱い |

## ビジネスルール

- トークンは `crypto/rand` による32バイトのランダム値をbase64url（パディングなし）でエンコードして生成する（[ADR-033](../adr/ADR-033-session-token-hashing.md) と同一パターン）
- 平文トークンはDBに保存しない。DBにはSHA-256ハッシュ値のみを保存する
- 有効期限は発行から30分とする（`expires_at = created_at + 30分`）
- 有効期限ちょうどの時刻は失効済みとして扱う（`now >= expires_at` で失効）
- 同じユーザーに対して新しいトークンを発行するとき、対象ユーザーの users 行を `SELECT ... FOR UPDATE` でロックしてから、同じユーザーの既存のトークンをすべて削除する（同時の申請を直列化し、未使用トークンを1件だけ残す）
- 再設定に成功したら、そのトークンのレコードを削除する（使用済みとして残さない）
- トークンの平文・トークンハッシュをログ・トレースに出さない（[情報取り扱いガイドライン](../guidelines/data-handling-guidelines.md)）

## 不変条件

- `expires_at` は `created_at` より未来
- 任意の1ユーザーが同時に保持する未使用トークンは0件または1件（新規発行で既存を削除するため）

## エラー

| エラー | 発生条件 |
|---|---|
| `ErrPasswordResetTokenNotFound` | リクエストのトークンハッシュに一致するレコードがDBに存在しない（未発行・使用済みで削除・新規発行で削除のいずれか） |
| `ErrPasswordResetTokenExpired` | 一致するレコードはあるが `expires_at` を過ぎている |
