# Event ドメイン

## 概要

ユーザーが登録したスケジュール上の予定を表すドメイン。タイトル・開始日時・終了日時・終日フラグを持ち、月ビュー・週ビューで表示される。

## 用語定義

| 用語 | 説明 |
|---|---|
| Event | ユーザーが登録した予定。ID・ユーザーID・タイトル・説明・開始日時・終了日時・終日フラグを持つ |
| 開始日時 (start_at) | 予定の開始時刻。終日予定の場合は日付のみを意味する（時刻は 00:00:00 として扱う） |
| 終了日時 (end_at) | 予定の終了時刻。開始日時以降でなければならない。終日予定の場合は日付のみを意味する |
| 複数日予定 | 開始日と終了日が異なる予定。月ビューでは各日のセルに、週ビューでは対象曜日を横断するブロックとして表示される |

## ビジネスルール

- 予定のタイトルは必須で空文字は許容しない
- 終了日時は開始日時以降でなければならない（end_at >= start_at）
- 予定はそれを作成したユーザーのみが参照・変更できる

## エラー

| エラー | 発生条件 |
|---|---|
| `ErrEventNotFound` | 指定した ID の予定が存在しない、またはそのユーザーに属していない |
| `ErrEventTitleEmpty` | 予定のタイトルが空 |
| `ErrEventInvalidDateRange` | end_at が start_at より前 |
