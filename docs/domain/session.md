# Session ドメイン

## 概要

認証済みユーザーのセッションを表すドメイン。セッションは PostgreSQL に保存され、HTTP-Only Cookie でセッション ID を管理する。

## 用語定義

| 用語 | 説明 |
|---|---|
| Session | ユーザーの認証セッション。ID・ユーザー ID・有効期限を持つ |

## ビジネスルール

- セッションは有効期限を持ち、期限切れのセッションは無効とみなす
- ログアウト時はセッションレコードを削除する
- ユーザー削除時はそのユーザーの全セッションを削除する
- セッションドメインはユーザー情報（メールアドレス・表示名）を持たない。必要な場合は User リポジトリから別途取得する
