# PRD-008 繰り返し予定

- 作成日: 2026-09-05
- 更新日: 2026-09-05

## 概要

毎週・隔週・第N曜日など柔軟なパターンで繰り返し予定を登録する機能。個別回のみの変更・削除にも対応する。

## 背景

拓也は定例会議を毎回手動登録している。さくらも週次MTGや隔週の1on1が複数ある。繰り返し登録の自動化で管理コストを大幅に削減できる。

## 目標

- よく使う繰り返しパターンを簡単に設定できる
- 繰り返しの一部だけ変更・削除できる

## 非目標

- カスタム曜日の複雑な組み合わせ（例: 月・水・金）以外の特殊パターン

## ユーザーストーリー

- 拓也として、毎週月曜10時の定例MTGを一度登録するだけで自動的に繰り返したい
- さくらとして、隔週木曜の1on1をまとめて登録し、特定の回だけキャンセルしたい

## 要件

- 繰り返しパターン: 毎日・毎週・隔週・毎月（同日）・毎月（第N曜日）
- 繰り返し終了条件: 終了日を指定 または 回数を指定 または 無期限
- 繰り返し予定の編集時に「この予定のみ変更」「以降すべて変更」「すべて変更」を選択できる
- 繰り返し予定の削除も同様に「この予定のみ」「以降すべて」「すべて」を選択できる

## 制約

- 繰り返しの最大回数は無期限設定の場合も2年分まで生成

## 成功指標

- 繰り返し設定が3ステップ以内で完了すること
- 特定回のみの変更が直感的に操作できること
