# PRD-002 予定管理

- 作成日: 2026-09-05
- 更新日: 2026-09-05

## 概要

予定の登録・編集・削除を行う基本機能。必要最小限の入力項目で素早く登録でき、後から詳細を追記できる。

## 背景

既存カレンダーの予定登録は入力項目が多く手順が煩雑。さくらは会議中に次の予定を素早く押さえたい、拓也は外出先でアポを即入力したい。「とりあえず日時とタイトルだけ入れてすぐ保存できる」ことが最重要。

## 目標

- タイトルと日時だけで予定を登録できる
- 必要に応じて詳細情報（メモ・場所・URL等）を追加できる
- 予定の編集・削除が簡単にできる

## 非目標

- 繰り返し予定（PRD-008で対応）
- 参加者招待・共有（PRD-003で対応）
- 自然言語入力（PRD-011で対応）

## ユーザーストーリー

- さくらとして、MTG中でも10秒以内に次のMTGを仮登録したい
- 拓也として、電話でアポを取った直後にアプリを開いて即座に入力したい
- さくらとして、登録した予定にZoom URLや資料リンクを後から追記したい

## 要件

- **必須項目**: タイトル、開始日時、終了日時
- **任意項目**: メモ（自由テキスト）、場所、URL
- カレンダー上の任意の場所をクリックして登録フォームを開ける
- 登録・編集フォームはモーダルで表示（画面遷移なし）
- 予定をクリックすると詳細表示 → 編集・削除ができる
- 削除前に確認ダイアログを表示する

## 制約

- 過去の予定も編集・削除できること
- フォームのバリデーション: 終了日時が開始日時より前の場合はエラー表示

## 成功指標

- タイトル + 日時入力から保存完了まで10秒以内に完了できること
- 操作ミス（誤削除等）を防ぐ確認ステップがあること
