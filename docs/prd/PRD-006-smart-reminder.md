# PRD-005 スマートリマインダー

- 作成日: 2026-09-05
- 更新日: 2026-09-05

## 概要

予定の前に複数タイミングで通知を送る機能。通知内容に会議URLや場所情報を含め、即座にアクションできる。

## 背景

さくらはZoom URLを直前に探して慌てることがある。拓也は移動が必要な商談の出発タイミングを自分で逆算している。段階的な通知と情報のワンストップ提供でこれらを解消する。

## 目標

- 予定前の複数タイミングで通知を受け取れる
- 通知から会議URL・場所へ直接アクセスできる

## 非目標

- メール通知（ブラウザ通知のみ）
- 他ユーザーへのリマインド送信

## ユーザーストーリー

- さくらとして、MTG 15分前・1分前にブラウザ通知を受け取り、通知からZoom URLを直接開きたい
- 拓也として、訪問アポの1時間前に通知を受け取り、出発の準備を始めたい

## 要件

- 予定ごとに通知タイミングを複数設定できる（例: 1日前・1時間前・15分前）
- デフォルト通知タイミングをアプリ設定で変更できる
- ブラウザのPush通知を使用する
- 通知にはタイトル・開始時刻・URL（設定されている場合）を含める
- 通知をクリックすると該当予定の詳細画面を開く

## 制約

- ブラウザの通知許可が必要なため、初回使用時に許可を促すUI
- バックグラウンドタブ・ブラウザ閉じている状態での通知はService Worker対応が必要

## 成功指標

- 設定した時刻の±30秒以内に通知が届くこと
- 通知クリックから予定詳細画面表示まで2秒以内
