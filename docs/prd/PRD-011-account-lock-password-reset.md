# PRD-011 アカウントロック・パスワードリセット

- 作成日: 2026-11-23
- 更新日: 2026-11-23

## 概要

パスワードの誤入力が続いたアカウントを一時的にロックする機能と、パスワードを忘れたユーザーがメールで再設定できる機能。メールの送信にはPRD-010のメール通知基盤を使う。

## 背景

現在、ログインに何度失敗しても制限がなく、パスワードの総当たりや流出したパスワードの使い回しによる不正ログインを防げない。
また、パスワードを忘れたユーザーはログインする手段がなく、作成した予定データにアクセスできなくなる。ロックを導入すると、ロックされた正規ユーザーが自力で復旧する手段も必要になる。

## 目標

- 同じアカウントに対して、パスワードを短時間に何度も試せなくする
- 不正ログインの試みがあったことを、アカウントの持ち主が知れる
- パスワードを忘れた・ロックされたユーザーが、自分で再びログインできる

## 非目標

- 2要素認証
- CAPTCHAによるログイン試行の制限
- 管理者によるロック解除
- 失敗回数に応じたロック時間の段階的な延長
- IPアドレス単位でのログイン試行の制限

## ユーザーストーリー

- さくらとして、誰かが自分のアカウントでパスワードを試し続けても、ログインされないようにしたい。なぜなら、予定には仕事や私生活の情報が含まれているから
  - 受け入れ条件: 5回連続でパスワードを間違えると、正しいパスワードを入力しても15分間ログインできない
- さくらとして、自分のアカウントがロックされたらメールで知りたい。なぜなら、身に覚えのないロックなら不正ログインの試みだと気付けるから
  - 受け入れ条件: ロックされたとき、登録メールアドレスにロックされた旨とパスワード再設定のリンクを含むメールが届く
- 拓也として、パスワードを忘れても、メールから再設定してすぐにログインしたい。なぜなら、商談前に予定を確認できないと困るから
  - 受け入れ条件: ログイン画面から再設定を申請し、届いたメールのリンクから新しいパスワードを設定すると、そのパスワードでログインできる
- 拓也として、自分でパスワードを打ち間違えてロックされても、15分待たずに復旧したい。なぜなら、急いでいるときに待てないから
  - 受け入れ条件: ロック中でもパスワードを再設定すると、ロックが解除され新しいパスワードでログインできる

## 要件

### 機能要件

アカウントロック:

- 同じアカウントでパスワードを5回連続で間違えると、そのアカウントを15分間ロックすること
- ログインに成功したら、失敗回数を0に戻すこと
- ロック中は、正しいパスワードを入力してもログインを拒否すること
- ロック中にログインしようとしたユーザーに、ロックされていることと、解除までの目安時間を表示すること
- ロックされたとき、登録メールアドレスへロック通知メールを送ること。メールにはパスワード再設定のリンクを含めること
- 15分経過したら、自動でロックを解除すること

パスワードリセット:

- ログイン画面から、メールアドレスを入力してパスワード再設定を申請できること
- 申請されたメールアドレスが登録済みの場合、再設定リンクを含むメールを送ること
- 再設定リンクから、新しいパスワードを設定できること
- 新しいパスワードの条件は、アカウント登録時の条件と同じにすること
- パスワードを再設定したら、ロックを解除し、失敗回数を0に戻すこと
- パスワードを再設定したら、他の端末のログインセッションをすべてログアウトさせること

### 非機能要件

- 再設定リンクの有効期限は発行から30分とし、1回使ったら無効にすること
- 同じアカウントで新しく再設定を申請したら、それ以前に発行したリンクを無効にすること

## 制約

- 未登録のメールアドレスで再設定を申請した場合も、登録済みの場合と同じ画面表示にする（登録の有無を第三者に知られないため）
- ログイン失敗時のメッセージは、メールアドレスとパスワードのどちらが誤っているかを区別しない

## 成功指標

- パスワードを忘れたユーザーが、再設定の申請から再ログイン完了まで3分以内に終えられること
- 1つのアカウントに対するパスワードの試行回数が、15分あたり5回以下に抑えられていること
