# PRD-001 カレンダービュー

- 作成日: 2026-09-05
- 更新日: 2026-09-05

## 概要

月単位・週単位でスケジュールを一覧表示する。予定の密度や時間帯が直感的に把握できるUIを提供する。

## 背景

既存カレンダーは情報が詰め込まれて視認性が低い。ペルソナのさくら・拓也どちらも「今日・今週何があるか」をパッと把握したいニーズを持つ。

## 目標

- 月ビューで月全体の予定密度を把握できる
- 週ビューで時間帯ごとの予定を把握できる
- ビューの切り替えが即座にできる

## 非目標

- 日ビュー（PRD-006 今日のタイムラインで対応）
- 印刷・エクスポート機能

## ユーザーストーリー

- さくらとして、週ビューで今週の会議スケジュールをひと目で確認し、空き時間を把握したい
- 拓也として、月ビューで今月の商談アポの密度を確認し、新規アポを入れられるかを判断したい

## 要件

- 月ビュー: カレンダーグリッド形式で1ヶ月分を表示。各日に予定件数または予定タイトルを表示
- 週ビュー: 時間軸（縦軸）× 曜日（横軸）のタイムライン形式で1週間を表示
- 月/週ビューをボタンまたはタブで切り替えできる
- 前後の月/週へのナビゲーションができる（「今日」ボタンで現在日に戻る）
- 予定をクリックすると詳細が確認できる

## 制約

- PC/タブレットのブラウザでの表示を最適化（スマホは考慮外）
- レンダリングは表示切り替え時に1秒以内

## 成功指標

- 週ビューで「空き時間はどこか」を5秒以内に判断できること
- ビュー切り替えの操作が直感的に行えること（初見ユーザーが迷わない）
