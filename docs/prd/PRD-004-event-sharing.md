# PRD-003 予定共有

- 作成日: 2026-09-05
- 更新日: 2026-09-26

## 概要

特定の予定を他のユーザーと共有する機能。URLシェアで予定情報を共有できる。

## 背景

チームや家族との予定調整のため、作成した予定を他者と共有したいニーズがある。さくらはチームメンバーとのMTG情報を共有し、拓也は商談アポを部下と共有したい。

## 目標

- 予定をURLリンクで共有できる
- 共有された予定を閲覧できる
- 登録ユーザーは共有された予定を自分のカレンダーに追加でき、追加後も共有元の変更に同期する

## 非目標

- カレンダー全体の共有（特定予定のみ）
- 共有先からの予定編集
- 出欠確認（RSVP）機能
- 未登録ユーザー（ログインしていない閲覧者）への「自分のカレンダーに追加」機能の提供
- 追加した予定への独自メモ追加・内容の上書き（同期表示のみ、追加先での加工は不可）

## ユーザーストーリー

- さくらとして、社内MTGの情報（日時・会議URL）をURLリンクで参加者に共有したい
- 拓也として、商談アポの日時・場所を部下にシェアしたい
- さくらとして、共有された予定を自分のカレンダーにも表示させたい。なぜなら、自分のスケジュール管理に組み込むことで会議の見落としを防ぎたいから
- さくらとして、自分のカレンダーに追加した予定は、共有元の日時変更に自動的に追従してほしい。なぜなら、共有元が変更したのに気づかず古い情報のまま参加してしまうことを避けたいから

## 要件

- 予定の詳細画面から「共有リンクを生成」できる
- 生成されたURLにアクセスすると予定の詳細（タイトル・日時・場所・メモ）を閲覧できる
- 共有リンクはログイン不要で閲覧可能
- 共有リンクの有効期限を設定できる（デフォルト: 予定終了日まで）
- ログイン済みユーザーが共有リンクの詳細画面を開いた場合、「自分のカレンダーに追加」操作ができる
- 追加した予定は共有元の予定を参照する形でカレンダービューに表示され、共有元のタイトル・日時・場所・メモの変更に自動的に追従する
- ユーザーはいつでも追加した予定を自分のカレンダーから削除（追加の取り消し）できる。取り消しても共有元の予定・共有リンクには影響しない
- 共有元の予定が削除された場合、追加していたユーザーのカレンダーからも当該予定の表示が消える

## 制約

- 共有リンク経由の閲覧者は予定の編集・削除不可
- メモ欄に含まれる情報も共有される点をユーザーに明示する
- 自分のカレンダーに追加した予定も、共有元からの編集不可の制約を引き継ぐ（同期表示のみで加工不可）

## 成功指標

- 共有リンク生成から相手に送るまで30秒以内に完了できること
- 共有リンクが期限後にアクセス不能になること
- 共有リンクの詳細画面から自分のカレンダーへの追加が3クリック以内で完了できること
