# PRD-001 ログイン・認証

- 作成日: 2026-09-05
- 更新日: 2026-09-05

## 概要

ユーザーアカウントの作成・ログイン・ログアウト機能。予定データをサーバーに紐付けて管理し、端末間同期と予定共有の基盤となる。

## 背景

予定データをユーザーごとに管理するため、および予定共有機能（PRD-004）を実現するために認証が必要。ローカルストレージでは端末間同期も共有も成立しない。

## 目標

- メールアドレス + パスワードでアカウントを作成・ログインできる
- ログイン状態でのみカレンダーを利用できる
- 複数端末から同じアカウントでアクセスできる

## 非目標

- GoogleやGitHubなどのOAuthログイン
- 2要素認証
- パスワードレス認証

## ユーザーストーリー

- さくらとして、アカウントを作成して自分の予定をサーバーに保存し、PCでも確認したい
- 拓也として、スマホで登録した商談アポをPCのブラウザでも確認したい

## 要件

- メールアドレス + パスワードでのアカウント登録
- ログイン / ログアウト
- 未ログイン状態でカレンダーにアクセスするとログイン画面へリダイレクト
- パスワードリセット（メールによる再設定リンク送信）
- ログインセッションの維持（ブラウザを閉じても一定期間ログイン状態を保持）

## 制約

- パスワードはハッシュ化して保存（平文保存禁止）
- セッショントークンはHTTP-Only Cookieで管理

## 成功指標

- アカウント登録からログイン完了まで1分以内に完了できること
- 異なる端末から同じ予定データにアクセスできること
