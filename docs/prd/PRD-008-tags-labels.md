# PRD-007 タグ＆カラーラベル

- 作成日: 2026-09-05
- 更新日: 2026-09-05

## 概要

予定にタグを付与し、カテゴリ別に色分け表示する機能。タグでフィルタリングしてカレンダーをカスタマイズできる。

## 背景

さくらはリモート/出社、仕事/個人など複数カテゴリの予定が混在している。色だけでは判別しにくいため、タグによる分類と視覚的な色分けで一覧性を高める。

## 目標

- 予定にタグを付けてカテゴリ分類できる
- タグごとに色を設定しカレンダー上で視覚的に区別できる
- タグでフィルタリングして特定カテゴリだけを表示できる

## 非目標

- タグの階層構造（フラットなタグのみ）
- タグの共有設定（ユーザー個人の設定として管理）

## ユーザーストーリー

- さくらとして、「リモート」「出社」タグを付けて色分けし、当日の働き方を一目で確認したい
- 拓也として、「商談」タグで絞り込んで今月の商談件数と日程を確認したい

## 要件

- ユーザーが任意のタグを作成・編集・削除できる
- 各タグに色を設定できる（カラーピッカーまたは選択肢から選ぶ）
- 予定に複数のタグを付与できる
- カレンダー上でタグの色が予定に反映される
- タグでフィルタリングすると該当タグを持つ予定のみ表示される

## 制約

- 1予定につき最大5タグまで

## 成功指標

- タグ設定後、カレンダー上でカテゴリ別の色分けが一目でわかること
- フィルタリング操作が2タップ以内で完了すること
