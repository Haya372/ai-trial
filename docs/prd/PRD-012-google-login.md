# PRD-012 Googleログイン

- 作成日: 2026-11-23
- 更新日: 2026-11-23

## 概要

Googleアカウントでアカウント登録・ログインできる機能。メールアドレス + パスワードで登録済みのユーザーは、本人確認のうえ既存のアカウントにGoogleアカウントを連携できる。

## 背景

現在のログイン手段はメールアドレス + パスワードだけで、ユーザーはこのサービス専用のパスワードを作って覚えておく必要がある。パスワードを忘れるとログインできなくなり、覚えやすい弱いパスワードや他サービスとの使い回しは不正ログインの原因になる。
普段使っているGoogleアカウントでログインできれば、ユーザーはこのサービス用のパスワードを管理しなくて済む。

## 目標

- Googleアカウントだけで、パスワードを作らずにアカウント登録・ログインできる
- メールアドレス + パスワードで登録済みのユーザーも、同じアカウントのままGoogleでログインできる

## 非目標

- Google以外のプロバイダー（Apple・GitHub・Microsoftなど）でのログイン
- 企業向けSSO（SAML・OIDCによる社内IdP連携）
- 連携したGoogleアカウントの解除・付け替え
- Googleカレンダーなど、Googleの他サービスとのデータ連携

## ユーザーストーリー

- さくらとして、Googleアカウントでワンクリックで登録したい。なぜなら、新しいパスワードを考えて覚えるのが面倒だから
  - 受け入れ条件: ログイン画面の「Googleでログイン」からGoogleアカウントを選ぶと、パスワードを入力せずにアカウントが作成され、カレンダーが表示される
- 拓也として、すでにメールアドレスで登録したアカウントのまま、Googleでもログインしたい。なぜなら、登録済みの予定をそのまま使い続けたいから
  - 受け入れ条件: 登録済みと同じメールアドレスのGoogleアカウントでログインすると、既存のパスワードを1回入力するだけで連携され、以降はGoogleだけでログインでき、既存の予定が表示される

## 要件

### 機能要件

- ログイン画面・アカウント登録画面に「Googleでログイン」を表示すること
- Googleアカウントのメールアドレスが未登録の場合、Googleでの認証だけでアカウントを作成しログインさせること
- Googleアカウントのメールアドレスが、メールアドレス + パスワードのアカウントとして登録済みの場合、既存のパスワードを入力させて本人確認し、成功したらGoogleアカウントを既存のアカウントに連携してログインさせること
- 連携済みのアカウントは、Googleとメールアドレス + パスワードのどちらでもログインできること
- Googleで作成したアカウントにメールアドレス + パスワードでログインしようとした場合、「Googleでログイン」を使うよう案内すること
- Googleでの認証をユーザーがキャンセルした場合、ログイン画面に戻すこと

### 非機能要件

- 「Googleでログイン」を押してからカレンダーが表示されるまで、Google側の操作時間を除いて3秒以内であること

## 制約

- Google側でメールアドレスが確認済みのGoogleアカウントだけを受け付ける
- 連携時の本人確認でのパスワード誤入力も、アカウントロック（PRD-011）の失敗回数に含める

## 成功指標

- 新規登録ユーザーのうち、Googleログインで登録したユーザーが50%以上になること
- 「Googleでログイン」を押してからカレンダーが表示されるまでを1分以内に完了できること
