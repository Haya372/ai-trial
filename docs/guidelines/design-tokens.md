# スタイルガイド

デザインシステムのビジュアル基盤。**何を使うかよりも、いつ・なぜ使うかを定義する**。
技術的な定義（CSS変数名）は二次的な情報として末尾に記載する。

---

## デザイン原則

1. **一貫性**: 同じ意味には同じ見た目を使う。コンポーネントをカスタムスタイルで上書きしない
2. **明快さ**: ユーザーが次に何をすべきか迷わない。情報の優先度を視覚的に表現する
3. **アクセシビリティ**: コントラスト比・フォーカス状態・スクリーンリーダー対応を常に確保する

## カラー

### アクションカラーの使い分け

コンポーネントの `variant` props に対応する。

| variant | 意味 | 使う場面 | 使わない場面 |
|---|---|---|---|
| `primary` | 最も重要なアクション | フォームのSubmit、確認のOK | 1画面に複数並べる |
| `secondary` | 補助アクション | 下書き保存、「後で」ボタン | 主要アクションと同格に見せたいとき |
| `destructive` | 取り消せない危険な操作 | 削除の最終確認ボタン | 削除操作の起点ボタン（最終確認ダイアログ内のみに使う） |
| `outline` | 低優先アクション | キャンセル、戻る | 主要CTAが他にない画面 |
| `ghost` | 極力目立たせない操作 | ツールバー・ナビのアイコンボタン | テキストラベル付きの目立つボタン |

**1画面に `primary` は1つを原則とする。**

### テキストカラーの使い分け

| トークン | 使う場面 |
|---|---|
| `text-foreground` | メインの本文・UI テキスト |
| `text-muted-foreground` | 補助情報・プレースホルダー・説明文・ラベル |
| `text-primary-foreground` | primary 背景上のテキスト（コンポーネント内部で使用） |
| `text-destructive` | エラーメッセージ・警告テキスト |

### 背景カラーの使い分け

| トークン | 使う場面 |
|---|---|
| `bg-background` | ページ全体の背景 |
| `bg-card` | カード・パネルの背景 |
| `bg-muted` | ホバー状態・非アクティブなタブ・コードブロック背景 |
| `bg-primary` | 主要アクションボタンの背景 |
| `bg-destructive/10` | エラー・警告の薄い背景色（Alert等） |

## タイポグラフィ

### 見出しの使い分け

| `Text` variant | タグ | 使う場面 |
|---|---|---|
| `h1` | `<h1>` | ページのメインタイトル（1ページに1つ） |
| `h2` | `<h2>` | セクション見出し |
| `h3` | `<h3>` | サブセクション・カードタイトル |
| `body` | `<p>` | 説明文・本文テキスト |
| `caption` | `<span>` | 補足情報・日時・メタデータ（`text-muted-foreground`） |
| `code` | `<code>` | インラインコード・変数名 |

**見出しレベルは視覚的なサイズではなく文書構造で決める。**
サイズを大きくしたいだけなら variant を変えず、Tailwind のクラスで調整しない（コンポーネントを拡張する）。

### フォントの使い分け

| フォント | 使う場面 |
|---|---|
| `font-sans`（デフォルト） | UI テキスト全般 |
| `font-mono` | コード・ファイルパス・技術的な識別子 |

## スペーシング

Tailwind の標準スケールを使う。カスタム値（`p-[13px]` 等）は使わない。

| スケール | px換算 | 用途の目安 |
|---|---|---|
| `gap-1` / `p-1` | 4px | アイコンとラベルの間隔 |
| `gap-2` / `p-2` | 8px | 関連する要素間の余白 |
| `gap-4` / `p-4` | 16px | コンポーネント内のパディング |
| `gap-6` / `p-6` | 24px | カード・パネルのパディング |
| `gap-8` / `p-8` | 32px | セクション間の余白 |

**余白は「要素間の関連性の強さ」を表す。関連が強いほど余白を小さくする。**

## ボーダー半径

| Tailwindクラス | 用途 |
|---|---|
| `rounded-md`（radius × 0.8） | 入力フィールド・小さいボタン |
| `rounded-lg`（radius = 0.625rem）| ボタン・バッジ・ポップアップ（デフォルト） |
| `rounded-xl`（radius × 1.4） | カード・モーダル・大きなコンテナ |
| `rounded-full` | アバター・ピル型バッジ |

## フォームの構造

フォーム要素は必ず `Label` と組み合わせて使う。エラー状態は `state="error"` で表現し、テキストで補足する。

```tsx
// OK: Label + Input + エラーテキストのセット
<div className="flex flex-col gap-1.5">
  <Label htmlFor="email">メールアドレス</Label>
  <Input id="email" state="error" aria-invalid aria-describedby="email-error" />
  <Text variant="caption" className="text-destructive">
    有効なメールアドレスを入力してください
  </Text>
</div>

// NG: Label なし、エラー状態の視覚的説明なし
<Input placeholder="メールアドレス" />
```

## フィードバックの使い分け

| コンポーネント | 使う場面 |
|---|---|
| `Alert` | ページ上部・セクション内の恒久的な通知（エラー・情報） |
| `Toast` | 操作完了の一時的な通知（保存成功・送信完了） |
| `Dialog` | ユーザーの入力・確認が必要な操作 |
| `AlertDialog` | 取り消せない操作の最終確認（削除等） |
| `Tooltip` | UI要素の補足説明（ホバーで表示） |
| `Badge` | ステータス・カテゴリ・数値の付加情報 |

**`Toast` は操作のフィードバックに使う。エラーの詳細説明には `Alert` を使う。**
